# 04. API REST

## Descripción
Núcleo Digital utiliza una API REST desarrollada con NestJS 12.
La documentación interactiva se encuentra disponible mediante Swagger.

## Swagger público
https://18.218.151.130.sslip.io/api/docs

## Autenticación
El sistema utiliza JWT para proteger los endpoints privados.
Los usuarios inician sesión con correo electrónico y contraseña.
Los permisos dependen del rol asignado.

## Módulos de la API
- Autenticación y usuarios.
- Menú y platillos.
- Pedidos y cocina.
- Mesas y reservas.
- Inventario.
- Pagos y comprobantes.
- Programa de lealtad.
- Notificaciones.
- Reseñas.
- Reportes.

## Consulta de endpoints
Swagger muestra las rutas, métodos HTTP, parámetros y respuestas documentadas.
Para consultar las operaciones disponibles, abrir el enlace público de Swagger.
