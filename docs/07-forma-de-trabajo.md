# 07. Forma de trabajo

## Metodología
El equipo organizó el desarrollo mediante historias de usuario y un tablero de seguimiento.

## Estrategia Git Flow
- main: código correspondiente a las versiones publicadas.
- develop: integración de funcionalidades.
- feature/*: desarrollo de historias de usuario.
- bugfix/*: corrección de errores durante el desarrollo.
- release/1.0.0: preparación de la primera versión.
- hotfix/*: correcciones urgentes posteriores a una publicación.

## Pull Requests
Los cambios se integran mediante Pull Requests para permitir su revisión.
Cada historia completada debe estar vinculada a su Pull Request y tarjeta del tablero.

## Versión de entrega
