## Cómo reportar un problema

1. Identificar el módulo afectado.
2. Describir el comportamiento esperado.
3. Describir el comportamiento observado.
4. Registrar los pasos para reproducir el error.
5. Adjuntar capturas o registros cuando corresponda.
6. Crear una incidencia en el tablero del proyecto.

## Limitaciones pendientes

Las funcionalidades no completadas y sus motivos
deben registrarse en 08-historias.md.

## Correcciones posteriores

Las correcciones urgentes después de la publicación
deben seguir el flujo de hotfix y generar una nueva versión.
